## What we do

Giralabs is a mobile development studio focused on building real, scalable applications for Android and iOS. We work exclusively with Flutter and Supabase — not because they are trending, but because they are the right tools for shipping fast, maintaining well, and scaling when the time comes.

We take on projects of every kind: productivity tools, marketplaces, SaaS clients, internal platforms, and consumer apps. What they all share is our standard: clean architecture, real-time data, and interfaces people actually want to use.

---

## Our stack

| Layer | Technology | Why |
|---|---|---|
| Mobile | Flutter + Dart | Single codebase, native performance, pixel-perfect UI |
| Backend & Database | Supabase | PostgreSQL, Auth, Storage and Realtime out of the box |
| State management | Riverpod / Bloc | Predictable, testable, scalable |
| CI/CD | GitHub Actions | Automated builds and deployments on every push |

We do not carry dead weight. Every dependency earns its place.

## How we work

- **One repo per project.** Clear boundaries, clean history.
- **Conventional commits.** The changelog writes itself.
- **Feature flags over long-lived branches.** Ship continuously, safely.
- **Documentation as a first-class deliverable.** If it is not documented, it does not exist.
